# GPU Cloud Atlas

Interactive dashboard of GPU and AI data center providers worldwide: pricing per GPU-hour, live and planned capacity, GPU models offered, headquarters and data center locations.

Static site, no build step. `index.html` + `app.js` (d3 v7), with a small `dash-runtime.js` that loads the datasets in `data/` and keeps filters in the URL.

Company logos provided by [Logo.dev](https://logo.dev). Flags from flag-icons (MIT).
